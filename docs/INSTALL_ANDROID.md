# Instalar CronoPet (APK) no Android

Build interno de teste — **não é da Play Store**. Serve pra você testar o
app antes do lançamento.

## 1. Baixar

**Mais fácil (QR code):** abra esta página no computador e escaneie o QR
com o celular:
https://expo.dev/accounts/jpmezian/projects/CronoPet/builds/a9617360-b55b-4f30-8652-29f2906d97d5

**Ou link direto do APK** (abra no navegador do próprio celular):
https://expo.dev/artifacts/eas/mV7UH89xY27zvm4ygFqRYR.apk

## 2. Permitir instalação de fontes desconhecidas

Como não vem da Play Store, o Android pede uma permissão única:

Configurações → Segurança (ou "Apps e notificações") → **Instalar apps
desconhecidos** → escolha o navegador onde baixou (Chrome, Drive, etc.) →
ative "Permitir desta fonte".

## 3. Instalar

Abra o arquivo `.apk` baixado (fica em Downloads) → toque em **Instalar** →
aguarde. Se aparecer um aviso do Play Protect, toque em "Instalar mesmo
assim".

## 4. Entrar

Use o e-mail/senha que você já cadastrou, ou crie uma conta nova. É o mesmo
backend da versão final — seus dados ficam salvos.

## 5. Reportar problema

Qualquer travamento, comportamento estranho ou tela confusa: tira print +
descreve o que você fez e manda pro João.
